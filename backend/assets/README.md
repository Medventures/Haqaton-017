# Ресурсы листа консультации

- `umc-horizontal.png` — логотип UMC из предоставленных пользователем материалов, копия ресурса интерфейса.
- `fonts/Inter-Regular.ttf`, `fonts/Inter-Bold.ttf` — статические начертания Inter, созданные из официального variable-шрифта [Google Fonts](https://github.com/google/fonts/tree/main/ofl/inter) с осями `opsz=14`, `wght=400/700` через `fontTools.varLib.instancer`. Лицензия SIL Open Font License 1.1 сохранена в `fonts/OFL.txt`.

Ресурсы входят в приложение: генерация PDF не загружает шрифты или изображения по сети. Inter включает русский и казахский алфавиты; шрифт встраивается в PDF.
