# Справочник МКБ-10

14 586 кодов и русских наименований из открытой публикации ТФОМС Республики Татарстан, срез 14.04.2021. Это справочные данные для демонстрации; актуальность национальных расширений и применимость к МИС Казахстана требуют проверки владельцем медицинского справочника.

Источник: https://www.fomsrt.ru/infinter/classifiers/fed_nsi/index.php?ELEMENT_ID=1616
Файл: https://www.fomsrt.ru/files2/MKB_2021_04_14.zip
Официальный актуальный реестр: https://nsi.rosminzdrav.ru/dictionaries/1.2.643.5.1.13.13.11.1005

JSON содержит версию, источник, SHA-256 исходного архива и пары code/name. Для обновления заменяется весь файл с сохранением схемы; ранее утверждённые листы сохраняют выбранный текст и код. Поиск выполняется локально, запросы с клиническими данными не уходят стороннему сервису. Выбор из каталога не означает постановку диагноза.
