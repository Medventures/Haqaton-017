# Правила работы

- Делать небольшие логически завершённые коммиты с описанием на русском и датой/временем (Asia/Qyzylorda, UTC+05:00).
- Вести `CHANGELOG.md` для каждого коммита; использовать `scripts/commit.py` после подготовки индекса.
- Каждую завершённую задачу с изменениями заканчивать необходимыми проверками, коммитом, push в `dev` и деплоем актуальных изменений на `medhub.ych.kz` без повторного запроса разрешения.
- После деплоя проверять работоспособность сайта. В итоговом ответе сообщать фактический результат коммита, push и деплоя; при сбое явно указывать, какой шаг не выполнен.
- Не включать в Git ключи, пароли, `.env`, настройки БД, записи приёмов, данные пациентов, пользовательские документы и артефакты проверок. Шаблоны `.env.example` содержат только пустые значения/заглушки.
- Тестировать внешние AI API только на синтетических данных, если пользователь явно не указал иное.
- База приложения — отдельная medhub; существующую базу postgres не изменять.
