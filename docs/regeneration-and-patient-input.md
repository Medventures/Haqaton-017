# Реквизиты пациента и повторный анализ

ИИН отображается как `XXXXXX XXXXXX`, телефон — как `+7 (XXX) XXX-XX-XX`. API сохраняет ИИН без пробелов, телефон в формате `+7XXXXXXXXXX`. Вставка полного номера с префиксом 8 и национального десятизначного номера также поддерживается. Поиск принимает ИИН с пробелами.

Дата рождения подставляется из первых шести цифр и признака века ИИН. Некорректная, будущая или неопределимая дата не подставляется. Дату можно указать по документу, включая случаи несовпадения с цифрами ИИН. Это важно, поскольку такое несовпадение само по себе не является ошибкой ИИН: [разъяснение Министерства юстиции](https://www.gov.kz/memleket/entities/adilet/press/news/details/5179?lang=ru).

## Перегенерация

В подсказках ИИ есть отдельные кнопки и общая кнопка «Перегенерировать все ответы с учётом правок». Для извлекаемых клинических полей предусмотрена кнопка «Дополнить с ИИ». Перед запуском интерфейс сохраняет текущие правки, включая изменения текста подсказок. Модель получает маскированную расшифровку и текущие клинические поля вместе с подсказками. Контекст маскируется и при автоматическом анализе после ASR.

- Обычные клинические поля дополняются. Заполненные числовые показатели сохраняются; противоречие отмечается предупреждением.
- Рекомендации по обследованиям перегенерируются целиком с учётом исправлений.
- Предварительные варианты диагноза дополняются; совпадающие текстовые абзацы не дублируются. Список кандидатов МКБ-10 объединяется по коду, максимум пять кандидатов. Смысловая дедупликация зависит от модели.
- Уже внесённые диагноз врача и его код остаются неизменными. Выводы ИИ не переносятся в диагноз автоматически.
- При выборе одного поля остальные ответы сохраняются.
- Подсказки ИИ по-прежнему исключены из PDF и обоих направлений интеграции с МИС. Изменения сохраняются в истории версий.

`POST /api/v1/encounters/{id}/generate` принимает `version` и необязательный `target` (по умолчанию `all`). Допустимы `ai_test_recommendations`, `ai_diagnosis_variants` и текстовые клинические поля, кроме диагноза, его кода и вида/формата приёма. Неизвестные значения отклоняются. Допускается анализ заполненных полей без расшифровки; требования согласия и проверки маскирования сохраняются.
