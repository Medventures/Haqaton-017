# Проверка разделения ИИ-подсказок и результата приёма

Дата: 30.09.2026, Asia/Qyzylorda.

## Изменения

- Вместо нового предварительного заключения генерируются отдельные рекомендации по дополнительным анализам/обследованиям и предварительные варианты диагноза по анамнезу. Обе подсказки предназначены только для просмотра. Старое поле доступно как архивная подсказка.
- PDF не содержит ИИ-подсказок. API чтения МИС и исходящий клиент используют разрешённый список клинических полей; старые задания отправки также фильтруются перед HTTP-запросом. Источники подсказок и служебные предупреждения не экспортируются.
- Обе ветки генерации (после ASR и отдельный повторный анализ) дополняют прежние поля, сохраняя текст врача. Точное повторение текста не добавляется второй раз. Отличающиеся числовые показатели сохраняют прежнее значение с предупреждением для врача; превышение лимита не обрезает исходный текст.
- Расшифровка свёрнута по умолчанию; ссылка на реплику раскрывает её. Форма занимает всю ширину. ИИ-подсказки вынесены в отдельную панель, итоговый результат врача находится последним блоком.

## Проверки

- Backend: 105 тестов пройдено. Включены оба сценария дополнения полей, сохранение прежних сведений, повторная генерация, устаревшие задания МИС, отсутствие ИИ-полей в списке/карточке интеграции и PDF.
- Frontend: 9 тестов пройдено; production-сборка успешна.
- Локальные контейнеры API, worker и UI пересобраны и запущены.
- В браузере выполнен реальный запрос OpenAI на синтетическом диалоге. Заранее заполненные жалобы и анамнез сохранены, сведения из диалога добавлены отдельными абзацами; две новые подсказки показаны отдельно, врачебные диагноз и назначения остались пустыми.
- Проверены раскрытие/сворачивание диалога и завершение синтетического приёма. По DOM: форма равна ширине рабочей области, итоговый блок последний, в панели ИИ нет полей редактирования, горизонтального переполнения нет.
- Две страницы синтетического PDF отрендерены Poppler и визуально проверены. Сохранены логотип UMC, оформление, разделы врача и нумерация; ИИ-подсказки отсутствуют.

Тестовые данные и изображения проверки находятся в игнорируемом каталоге `artifacts/`. Реальные медицинские данные во внешние AI API при проверке не отправлялись. Речевой API этой задачей не изменён; проверка его вызова выполнена автоматическими тестами с подменой провайдера.
